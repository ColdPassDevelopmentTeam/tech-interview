## 데이터 무결성 개념

### 개념

데이터의 정확성, 일관성, 유효성, 신뢰성을 보장하는 성질

데이터가 저장, 조회, 수정, 삭제되는 과정에서 정확하고 일관성 있게 유지되도록 보장하는 것

데이터가 어떤 경우에도 아래처럼 되지 않고 완전하고 처음 의도한 대로 올바르게 유지되는 것

- 변질됨
- 손상됨
- 중복됨
- 논리적으로 모순됨
- 잘못된 데이터가 들어옴

### 핵심 요소

- **정확성**:
    - 저장된 데이터가 실제 현실 세계의 값과 일치하는 정도를 의미.
    - 데이터가 올바르고 오류나 중복이 없이 입력·저장됨을 의미.
    - 예시 : 고객의 주소 데이터가 실제 거주하는 주소와 동일해야함.
- **일관성**:
    - 데이터베이스 내의 모든 데이터가 서로 모순 없이 일관된 상태를 유지하는 것을 의미.
    - 데이터베이스의 여러 테이블이나 필드 간 논리적 관계가 항상 올바르게 유지됨을 의미.
    - 예시 : 한 테이블에서 고객의 등급이 'VIP'로 변경되었다면, 다른 관련 테이블에서도 해당 고객의 등급 정보가 동일하게 'VIP'로 보여야함.
- **완전성**:
    - 데이터에서 누락된 값이 없어야 함을 의미.
    - 데이터가 빠지지 않고 전체적으로 온전하게 존재함을 의미.
    - 예시 : 사람 테이블에 주민번호가 비어있으면 안됨.
- **유효성**:
    - 데이터가 미리 정해진 규칙이나 형식에 맞게 저장되는 것을 의미
    - 정의된 규칙이나 조건에 맞게 데이터가 저장되어야 함을 의미.
    - 예시 : '성별' 필드에는 '남성' 또는 '여성'이라는 정해진 값만 입력되도록 하는 것.

### 중요성

- **데이터 신뢰성 보장**
    - 데이터는 곧 자산이기 때문에, 무결성이 보장되지 않으면 신뢰할 수 없음
    - 조직 내외부의 신뢰를 구축하는 데 필수적
    - 신뢰성 있는 데이터는 고객 신뢰, 비즈니스 파트너와의 신뢰로 이어짐.
- **정확한 의사결정 지원**
    - 데이터를 기반으로 중요한 결정 내리는데 데이터에 오류가 있다면, 잘못된 예측으로 이어져 큰 손실
    - 신뢰할 수 있는 데이터 제공되어 잘못된 정보로 인한 잘못된 의사결정을 방지
- **중복/오류 최소화**
    - 중복된 데이터, 잘못된 데이터가 많아지면 데이터 관리 비용 증가
    - 저장 공간 절약, 성능 향상
- **보안 강화**
    - 허가되지 않거나 악의적인 데이터 변경을 막는 방어선 역할
    - 비정상적인 데이터 삽입, 불법적인 데이터 변경, 잘못된 삭제 방지 가능
- **시스템 안정성**
    - 트랜잭션 처리의 일관성 유지
    - 데이터 타입이나 범위에 대한 규칙으로 예기치 않은 값이 입력되어 오류가 발생하는 것 방지
